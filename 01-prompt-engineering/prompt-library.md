# Prompt Library

| Prompt Name | Workplace Task (When to use it) | Framework | Prompt | Expected Output |
|---|---|---|---|---|
| Query Optimizer | I use this when a complex SQL query is running slowly and needs performance tuning. | C.A.R.E. | **Context:** We have a slow-running query joining 4 large tables. **Action:** Analyze the query and suggest index optimizations. **Role:** Senior Database Administrator. **Expected Output:** A bulleted list of suggested indexes and the rewritten optimized query. | Optimized SQL query with comments and index recommendations. |
| PL/SQL Documenter | I use this when I need to understand and document legacy database triggers or packages. | R.C.T.O. | **Role:** Systems Analyst. **Context:** A legacy PL/SQL trigger has no documentation. **Task:** Write technical documentation for this code snippet. **Output:** A markdown table defining variables, logic flow, and execution conditions. | Technical documentation table explaining the trigger. |
| Downtime Communicator | I use this to notify stakeholders about scheduled database maintenance. | R.C.T.O. | **Role:** IT Operations Lead. **Context:** Oracle database needs a 2-hour offline migration this weekend. **Task:** Draft an email to department heads. **Output:** A professional, concise email stating the downtime window and impact. | A professional notification email template. |
| Error Log Summarizer | I use this when the system generates hundreds of lines of error logs and I need to find the root cause fast. | C.A.R.E. | **Context:** The system crashed and generated 200 lines of error logs. **Action:** Extract the root cause and affected tables. **Role:** DBA. **Expected Output:** A short summary paragraph identifying the primary ORA- error code. | A concise paragraph identifying the specific error and its source. |
| Schema Normalizer | I use this when designing a new feature that requires creating new relational tables. | C.A.R.E. | **Context:** Designing a new user authentication module. **Action:** Suggest a normalized database schema (3NF). **Role:** Data Architect. **Expected Output:** SQL CREATE TABLE statements with primary and foreign keys. | SQL schema definitions with proper relationships. |
