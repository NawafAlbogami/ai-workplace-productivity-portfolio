# Professional Writing Workflow Example

## 1. AI-Generated Draft
[Draft text generated by AI based on a prompt asking to notify staff about a database outage]
"Hey everyone, the database will be down on Saturday for 2 hours. We are migrating to a new server. You won't be able to access the system. Let IT know if you have issues."

## 2. Fact Verification
- Confirmed the exact downtime window (Saturday, 12:00 AM to 02:00 AM AST).
- Verified that the migration only affects the reporting module, not the core transaction system.

## 3. Tone Refinement
- Shifted the tone from casual to professional and authoritative.
- Added specific contact details for emergency IT support.

## 4. Human Sign-off
- Reviewed and approved by: نواف مسلط البقمي (Systems Analyst).

## 5. Final Version
Subject: SCHEDULED MAINTENANCE: Reporting Database Offline on Saturday (12:00 AM - 02:00 AM)

Dear Team,

Please be advised that the IT Infrastructure team will be conducting a scheduled migration of our primary reporting database this weekend. 

**Maintenance Window:**
- **Start:** Saturday, September 19, 12:00 AM (AST)
- **End:** Saturday, September 19, 02:00 AM (AST)

**Impact:**
During this two-hour window, all BI dashboards and historical reporting tools will be temporarily unavailable. Core transaction processing and the main application will remain fully functional and unaffected.

If you have any urgent reports to generate, please ensure they are completed prior to the maintenance window. For emergency technical assistance during this period, please contact the IT Helpdesk at ext. 5555.

Best regards,

نواف مسلط البقمي
Database Administrator / Systems Analyst
