## Project Overview
This repository serves as a professional portfolio demonstrating the application of generative AI tools in database administration and systems analysis. I utilized AI to optimize PL/SQL queries, draft technical documentation, extract actionable insights from unstructured system logs, and plan database migration workflows while adhering to strict verification and data privacy standards.

## Selected Workplace Scenario
Database Administrator (DBA) / Systems Analyst responsible for maintaining database performance, optimizing Oracle SQL queries, troubleshooting system triggers, and communicating technical downtime to non-technical stakeholders.

## Key Learnings
1. AI accelerates legacy PL/SQL code documentation significantly.
2. Verification is mandatory to prevent destructive SQL commands (e.g., accidental table drops).
3. Structuring prompts (C.A.R.E.) yields precise indexing strategies rather than generic advice.

## Responsible Use Statement
This portfolio does not contain real confidential, private, or sensitive organizational data. All database schemas, logs, and query examples are fictional and anonymized. AI-generated code was strictly reviewed for syntax and performance implications before approval.
